Python

pip install ollama
from ollama import chat
r = chat(model="llama3.2:3b", messages=[{"role":"user","content":"..."}])
r.message.content        # the answer

# streaming: same generation, delivered piece by piece
for chunk in chat(model=..., messages=..., stream=True):
    print(chunk.message.content, end="", flush=True)
chunk.eval_count         # statistics are in the LAST chunk (chunk.done is True)

# options: control the sampling
chat(model=..., messages=..., options={"temperature": 0})
chat(model=..., messages=..., options={"temperature": 1.5, "seed": 42})

# format: force the shape of the answer with a schema
from pydantic import BaseModel
class Invoice(BaseModel):
    invoice_number: str
    order_number: str | None      # can be absent: allow None
    total: float
r = chat(model=..., messages=..., format=Invoice.model_json_schema(),
         options={"temperature": 0})
invoice = Invoice.model_validate_json(r.message.content)   # raises ValidationError
invoice.model_dump_json()     # object back to one line of JSON

# other host
from ollama import Client
Client(host="http://localhost:11434").chat(...)

Response fields

eval_counttokens generated
eval_durationnanoseconds generating
prompt_eval_counttokens in the prompt
load_durationnanoseconds loading the model
total_durationnanoseconds in total
done_reasonwhy generation stopped

tokens/s = eval_count / (eval_duration / 1e9)

Sampling options

temperaturerandomness of the choice of the next token. Default 0.8. 0 = always the most likely token = same answer every run.
seedfixes the random numbers. Same seed + same prompt = same text, also at high temperature.

Extraction, classification, evals: temperature: 0. Text for humans (briefing): default is fine. Source: Modelfile parameters.

Structured output

format limits the tokens the model can pick, so the output always has the shape of the schema. It checks shape, not truth: a required field is always filled, also when the document does not have the value. Fields that can be absent: ... | None. format="json" gives valid JSON with free field names. Source: structured outputs.

Passing options through functions

def extract(text, **options):          # collects: {"temperature": 0}
    chat(..., options=options)         # OK: chat() wants a dict
    helper(text, **options)            # OK: unpacks again
    helper(text, options=options)      # BUG: wraps it -> {"options": {...}}, ignored by Ollama

Model in memory

First call loads the model (load_duration). It stays loaded 5 minutes (FAQ). keep_alive="30m" in chat() keeps it longer; 0 unloads now; ollama stop llama3.2:3b unloads from the shell.
