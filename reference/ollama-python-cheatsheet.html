Ollama + Python cheat sheet

From Lesson 1. Sources: ollama-python, API docs.

Shell

ollama -v                 # version / is it installed
ollama pull llama3.2:3b   # download a model
ollama run llama3.2:3b    # chat in terminal (/bye to exit)
ollama list               # downloaded models
ollama ps                 # models loaded now
nvidia-smi                # GPU memory use

Python

pip install ollama
from ollama import chat
r = chat(model="llama3.2:3b", messages=[{"role":"user","content":"..."}])
r.message.content        # the answer

# streaming
for chunk in chat(model=..., messages=..., stream=True):
    print(chunk.message.content, end="", flush=True)

# other host
from ollama import Client
Client(host="http://localhost:11434").chat(...)

Response fields

eval_counttokens generated
eval_durationnanoseconds generating
prompt_eval_counttokens in the prompt
load_durationnanoseconds loading the model
total_durationnanoseconds in total
done_reasonwhy generation stopped

tokens/s = eval_count / (eval_duration / 1e9)
